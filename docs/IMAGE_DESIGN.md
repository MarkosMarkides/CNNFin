# Image Design

The CNN input is a four-panel image generated from the previous 30 one-hour candles for each sample.

The image generator lives in:

```text
image_generation/image_generator.py
```

Full image generation is orchestrated by:

```text
exploration/image_builder.ipynb
```

## Image Window

For a sample at row `t`, the image uses:

```text
[t-29, t]
```

This is controlled by:

```yaml
image_lookback: 30
```

The supervised label still uses the future 96 one-hour candles after `t`.

## Output Size

The full training image source size is:

```text
448 x 448
```

This comes from:

```yaml
image_size_each: 224
```

Each of the four panels is `224 x 224`.

The CNN notebook resizes images to:

```yaml
cnn_input_size: 224
```

## Four Panels

Panel order:

```text
top-left:     altcoin-vs-BTC return divergence
top-right:    BTC candlestick chart
bottom-left:  BTC Gramian Angular Field
bottom-right: technical indicator heatmap
```

## Top-Left: Altcoin-vs-BTC Divergence

The divergence panel uses altcoin close columns and BTC close.

For each altcoin, it computes 1-hour percentage returns and subtracts BTC returns over the same image window.

The current palette is the original-paper blue-white-red divergence palette:

```text
blue -> white -> red
```

The target alias `BTCUSDT_Close` is excluded from this panel so BTC is not accidentally treated as an altcoin row.

## Top-Right: Candlestick

The candlestick panel uses BTC:

- `Open`
- `High`
- `Low`
- `Close`

It renders a clean chart without axes or labels.

## Bottom-Left: GAF

The Gramian Angular Field panel uses BTC close values over the image window.

The close series is normalized within the window and converted into a GAF matrix.

## Bottom-Right: Indicator Heatmap

The indicator heatmap uses the current locked 13 indicators:

- `return_1`
- `return_10`
- `RSI_14`
- `ATR_14`
- `CCI_20`
- `MACD26_12`
- `SIGNAL26_12`
- `HIST26_12`
- `VWAP_14`
- `Volatility_12`
- `%K_14`
- `%D_14`
- `OBV`

These are intentionally left unchanged for the current experiment.

## Preview Images

Preview images are generated by default into:

```text
artifacts/cnnfin_1h/image_preview/
```

The preview manifest is:

```text
artifacts/cnnfin_1h/image_preview/preview_manifest.pkl
```

Preview images are not the full training dataset.

## Full Images

Full image generation is expensive and should usually run on Jarvis.

In `image_builder.ipynb`, set:

```python
RUN_FULL_IMAGE_BUILD = True
```

Full images are written to:

```text
artifacts/cnnfin_1h/images/{split}/{sample_id}.png
```

The full image manifest is:

```text
artifacts/cnnfin_1h/processed/image_manifest.pkl
```
